# Data Manifest

| File | Description | Tracked |
|---|---|---|
| `data/donor_number.csv` | Donor-number dataset for model training. | Yes |
| `data/esp_345.csv` | ESPmin and ESPmax dataset. | Yes |
| `data/oxidation_potential.csv` | Oxidation-potential dataset. | Yes |
| `data/pubchem_cleaned_data.csv` | Cleaned PubChem-derived screening library. | Yes |
| `data/commercially_available_candidates.csv` | Cleaned 51-candidate commercially available screening output. | Yes |
| `data/previously_unexplored_candidates_si_table.csv` | Simplified SI-style table for 36 previously unexplored candidates. | Yes |
| `data/li_binding_energy_complete.xlsx` | Li+ binding-energy audit dataset. | Yes |
| `large_data_not_tracked/pubchem.csv` | Raw PubChem export. Excluded because it exceeds GitHub's standard 100 MB single-file limit. | No |

All dataset column names in tracked files are English.
